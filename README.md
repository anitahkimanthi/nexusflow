# NexusFlow

NexusFlow is a portfolio concept for an AI-powered workflow orchestration platform. It demonstrates how modern teams can design, automate, monitor, and improve operational workflows using intelligent routing, AI insights, and clean product design.

## Overview

NexusFlow focuses on turning requests, tasks, and decisions into structured operational systems. The project was built to showcase full-stack product thinking, frontend engineering, AI workflow concepts, and modern interface design.

## Features

- AI workflow orchestration concept
- Visual workflow builder
- Operational dashboard
- AI insights section
- Light and dark theme support
- Redux-powered theme state management
- Responsive layout
- Smooth animations with Framer Motion

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Redux Toolkit
- Framer Motion
- Lucide React

## Getting Started

Install dependencies:

```bash
yarn install
```
